# M0 小程序测试 Spec

> TDD 测试规格 · 在开发者工具里验证
> 每个测试用 automator/MCP 执行

## 测试 1：首页渲染

**前提**：开发者工具打开项目，编译成功
**步骤**：
1. 打开 pages/index/index
2. 截图
**断言**：
- 页面标题显示"AI智作PPT模版社"
- 场景筛选 tag 存在（全部/工作汇报/答辩/学术研究/商务展示）
- skill 卡片列表存在（≥1 个）
- 未登录显示"登录"按钮

## 测试 2：场景筛选

**步骤**：
1. 点击"工作汇报" tag
**断言**：
- skill 列表过滤为工作汇报场景
- 至少 2 个 skill 显示

## 测试 3：详情页

**步骤**：
1. 点击任一 skill 卡片
2. 跳转到 pages/detail/detail?id=xxx
**断言**：
- 显示 skill 名称
- 显示"获取方式"三 agent（Codex/豆包/WorkBuddy）
- 显示价格
- 显示底部购买按钮

## 测试 4：登录页

**步骤**：
1. 点击"登录"按钮
2. 跳转到 pages/login/login
**断言**：
- 显示"AI智作PPT模版社"标题
- 显示用户协议 checkbox
- 显示"微信一键登录"按钮
- 未勾选协议时点登录提示"请先同意"

## 测试 5：预览页

**步骤**：
1. 在详情页点击预览区
2. 跳转到 pages/preview/preview
3. 点击"渲染预览"按钮
**断言**：
- canvas 存在
- 点击渲染后显示"渲染完成"

## 测试 6：我的页

**步骤**：
1. 切换到 tabBar "我的"
**断言**：
- 显示用户信息（登录/未登录状态）
- 显示会员体系（2.9/9.9/19.9/99.9 四档）
- 显示社群入口

## 测试 7：console 无报错

**步骤**：
1. 编译后遍历 5 个页面
2. 读 console logs
**断言**：
- 0 个 error 级别日志

## 测试 8：typecheck

**步骤**：
1. npx tsc --noEmit
**断言**：
- EXIT=0

## 测试 9：app.json 完整性

**步骤**：
1. 读 app.json
**断言**：
- pages 列表含 5 个页面路径
- tabBar.list 含 3 个 tab
- cloud: true

## 测试 10：页面 4 件套完整

**步骤**：
1. 遍历 5 个页面目录
**断言**：
- 每个页面有 .ts/.wxml/.wxss/.json 4 件套
