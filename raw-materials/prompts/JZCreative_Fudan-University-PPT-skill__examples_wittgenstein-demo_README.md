# Wittgenstein Demo Renderings

这个文件夹收录了一套使用 `fudan-ppt` skill 生成的 20 页示例演示文稿渲染图，主题为“维特根斯坦：语言的限度与生活形式”。

These images show a 20-slide demo deck generated with the `fudan-ppt` skill on the topic “Wittgenstein: The Limits of Language and Forms of Life.”

## Contents

- `slides/slide-01.png` 至 `slides/slide-20.png`：逐页 PNG 渲染图。
- `montage.webp`：20 页总览拼图。

## Note

示例仅用于展示 skill 的视觉系统、跨格式布局一致性和多风格演示能力，并非复旦大学官方模板。

This demo is provided only as a visual reference for the skill’s layout system, cross-format parity, and style range. It is not an official Fudan University template.
